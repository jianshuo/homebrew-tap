# homebrew-tap

Homebrew tap for [@jianshuo](https://github.com/jianshuo)'s tools.

## Install

```sh
brew tap jianshuo/tap
brew install ccline          # zsh inline AI - type a thought, get an answer
brew install ccglass         # logging proxy + dashboard for coding agents
brew install cchour          # time report for AI coding sessions
brew install --cask cclight  # Claude Code status on the MacBook notch
```

Or in one step without tapping first:

```sh
brew install jianshuo/tap/ccline
```

## Tools

| Tool | What it does | Repo |
|------|--------------|------|
| `ccline` | Type a thought at your zsh prompt, get an answer via Claude Code | [jianshuo/ccline](https://github.com/jianshuo/ccline) |
| `ccglass` | See exactly what your coding agent sends to the model | [jianshuo/ccglass](https://github.com/jianshuo/ccglass) |
| `cchour` | How much time you actually spend in AI coding tools | [jianshuo/cchour](https://github.com/jianshuo/cchour) |
| `cclight` | MacBook notch lights up with Claude Code status | [jianshuo/cclight](https://github.com/jianshuo/cclight) |
